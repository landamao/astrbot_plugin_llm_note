# 📓 笔记本插件 (LLM Note)

为 AstrBot 提供持久化记忆能力：大模型可以记住用户信息、偏好、关系等，并支持群组全局笔记，实现多用户间的记忆连贯性。

---

## ✨ 功能

- **个人笔记**：按群/私聊为每个用户独立存储（上限 20 条，超出自动淘汰最旧）
- **全局笔记**：群组级共享笔记（上限 40 条），群内所有成员对话时可见
- **自动注入**：每轮对话自动将笔记附加到 prompt，模型据此"记住"信息；笔记不写入会话历史、不破坏提示词缓存
- **LLM 自主管理**：模型可自行调用工具增删改查笔记（`edit_note`、`search_note`、`get_note`、`get_user_id`，参数说明见 `main.py` 中各工具的 docstring）
- **隐私保护**：笔记仅对模型可见，由模型甄别是否、如何透露给用户
- **存储**：SQLite（`notes.db`），旧版 `data.json` 首次加载自动迁移

---

## 📦 安装

```bash
git clone https://github.com/landamao/astrbot_plugin_llm_note.git
```

放入 AstrBot 的 `plugins` 目录后重启即可，开箱即用。

---

## 🔧 配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `自动删除时长` | int | 24 | 清空笔记时备份文件多少小时后自动删除，0 代表永不删除 |
| `全局共享笔记` | bool | false | 开启后注入所有群组笔记，非当前群的以 `[来自其他会话，仅供参考]` 形式附加在末尾 |

---

## 📋 用户指令

| 指令 | 说明 |
|------|------|
| `/清空笔记 [群ID]` | 清空当前群/私聊笔记，执行前自动备份。私聊可清空自己的笔记（10 分钟冷却）；群聊需管理员 |
| `/恢复笔记 <文件名>` | 从备份恢复。管理员可跨群恢复；非管理员仅限自己私聊数据（10 分钟冷却） |
| `/清空笔记日志` | 清空错误日志文件，仅管理员 |

## 💬 效果示例

> **用户**：帮我记一下我喜欢喝冰美式，少冰。
> **机器人**：已记录～（模型自主调用工具写入笔记）

> **用户**：我上次让你记的我的生日是哪天？
> **机器人**：你的生日是 5 月 20 日。（笔记自动注入，模型无需查库）

> **用户**：群里的"小王"是谁？
> **机器人**：小王的 ID 是 123456789。（模型通过昵称反查用户 ID）

---

## ⚠️ 注意事项

- 全局笔记仅在群聊中有效，私聊只有个人笔记
- 清空笔记产生的备份（`data_*.json`）存于插件数据目录，默认 24 小时后自动删除，也可手动删除
- 数据存于 `notes.db`（SQLite），请勿手动修改；旧版 `data.json` 迁移后重命名为 `data.json.bak`
- 笔记内容未加密，仅存储在本地，保障服务器安全即可
- 用户昵称缓存重启后清空，收到新消息会自动重新填充
